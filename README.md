# Todo API

개인 일정 관리 API 프로젝트입니다.

2년 이상의 개발 공백기 이후 Java/Spring Boot 개발 감각을 되살리고,
REST API와 JPA를 다시 학습하기 위한 미니 프로젝트입니다.

## 📌 프로젝트 정보

- 개발 기간: 2026.09 ~
- 개발 인원: 1명
- 개발 목적: Java/Spring Boot 개발 감각 회복

## 🛠 기술 스택

- Java 17
- Spring Boot
- Spring Data JPA
- H2 Database
- Gradle
- STS
